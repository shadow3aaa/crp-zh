C++ to Rust Phrasebook

库

C++ 程序通常使用操作系统发行版自带的库，或者将库直接集成到项目中。

Rust 程序则更倾向于依赖一个名为 crates.io 的 Rust 库（“crate”）中央注册表（以及一个由这些 crate 的代码内文档生成的中央文档库 docs.rs）。对 crate 的依赖通过 Cargo 包管理器 进行管理。

Lib.rs 是一个很好的资源，可以按类别查找流行的 crate。

供应链管理

在需要管理库供应链的场景下，Cargo 可以配合 自定义的自管或组织托管注册表 或 从 crates.io 获取的依赖库的本地化版本 使用。

这两种方式都为依赖项审查和供应链安全提供了机制。

不涉及本地化或自定义注册表的供应链安全解决方案正在推进中。

# C++ to Rust Phrasebook

这是CRP(C++ to Rust Phrasebook)的一个简体中文翻译版本的源码 [CRP](https://cel.cs.brown.edu/crp/).
点击这里[CRP-ZH](https://shadow3aaa.github.io/crp-zh/)进行阅读

## Building locally

Install [mdBook](https://github.com/rust-lang/mdBook/) and [mdbook-quiz](https://github.com/cognitive-engineering-lab/mdbook-quiz). Then run:

```
mdbook serve
```
